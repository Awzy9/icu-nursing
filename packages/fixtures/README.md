# @icu/fixtures

Synthetic, **nonclinical** fixtures used to develop and test the website and the native apps: questions, cases, skills, medications and equipment modules about fictional scenarios (ferry office, harbour, garden). Every item has a `SYN-` code and states that it contains no clinical content. Nothing here is derived from, or may be copied from, the clinical drafts under `content/drafts`; `tests/unit/fixtures-package.test.ts` and the mobile bundle check enforce this.
